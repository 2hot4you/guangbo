# 光波互联六个差异化一级内页设计

## 目标

在现有首页视觉体系上重构 `/ai`、`/idc`、`/madeinchina`、`/network`、`/energy`、`/about` 六个一级内页。页面继续使用黑、白、浅灰和荧光黄绿色，但不再由同一个“首屏 + 卡片网格”模板批量生成。共享 Header 的第一个一级入口为“首页”。

## 内容与事实边界

- 正文以 `docs/网站各板块介绍页文案.md` 和现有结构化内容为基础，可以补充解释、选择方法、实施步骤和服务边界。
- 不编造客户名称、合作资质、项目规模、价格、SLA、资源库存、实时模型可用性或联系方式。
- 模型品牌仅用于生态与能力介绍；页面持续说明实际开放型号与价格以平台目录为准。
- IDC、专线和能源资源使用“合作资源”“方案对接”等准确表达，不暗示相关资产全部自有。
- 尚无确认图片时使用有明确标签的视觉占位，不引入来源不明的商业图片。

## 共用设计语言

- 颜色、字体、间距、按钮、细线、圆形轨道图形与低频动效沿用首页。
- 每页仅复用容器、章节标题、编号、文本链接、视觉占位和选择清单等基础原语，不复用完整页面骨架。
- 首屏和长内容区交替使用白、浅灰、黑色或荧光色背景，保持 ZenMux 式大字号、留白和强对比。
- 每页只能有一个 `h1`；内容模块使用带可寻址 `id` 的语义化 `section`，图示使用 `figure` 与可读说明。
- 所有页面在手机端保持内容顺序合理、无横向溢出；连续轨道动效在 `prefers-reduced-motion: reduce` 下停止。

## 模块计数规则

- 每个页面至少 8 个具有独立信息目的的内容模块。
- 首屏可计为一个模块；Header、Footer、面包屑和通用“继续了解”区不计入。
- 页面根内容用 `data-landing-page` 标识，可计数模块使用 `data-content-module` 标识，自动化测试检查每页不少于 8 个。
- 模块必须分别回答“提供什么、适合谁、怎样选择、如何实施、有哪些边界”等问题，不允许通过重复文案或纯装饰区域凑数。

## 组件与内容结构

- 保留 `MarketingPage` 的结构化内容源，各一级页面补齐至少 8 个 `ContentSection`。
- 新建一级内页基础原语，负责编号、模块语义、视觉占位、步骤轴和链接列表。
- 六个页面使用独立 React 组件；`MarketingPageView` 按顶级路径选择组件，二级模型页和 IDC 产品页继续使用现有模板。
- 新增独立样式文件承载一级内页视觉，避免继续扩张已有通用卡片样式。

## 验收

- 桌面和移动 Header 的首个导航入口均为“首页”，当前页状态正确。
- 六个一级内页各有一个 `h1`、至少 8 个 `data-content-module`，且模块 ID 唯一。
- 六页的结构性类名、核心图示和信息顺序不同，而不是同一网格换文案。
- 所有结构化正文都在服务端 HTML 中，内部链接只指向已批准公开路由。
- 360、768、1280 和宽桌面视口无横向溢出，键盘焦点清楚，减少动效偏好生效。
- 单元测试、类型检查、Lint、生产构建及浏览器检查全部通过。
