# 光波互联官网前端基础框架 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 建立采用 Next.js App Router、React 19、TypeScript、Tailwind CSS 4 与 HeroUI v3 的光波互联中文官网基础框架，并交付 14 条有真实内容的公开路由、完整公共布局、基础 SEO、HeroUI MCP 接入和浏览器验收。

**Architecture:** 公开页面默认使用 Server Components 和静态预渲染，只有桌面下拉导航、手机 Drawer 等交互使用小型 Client Components。类型化路由清单和本地结构化正文是导航、页脚、metadata、canonical、sitemap 与相关链接的单一来源；首页、业务总览、模型分类、产品方案和公司页使用五类模板渲染。

**Tech Stack:** Next.js 16.3.6、React/React DOM 19.3.0、TypeScript 5.9.3、Tailwind CSS 4.3.3、HeroUI 3.2.6、pnpm 9、Vitest 5、Testing Library、Playwright 1.63、ESLint 9。

**Spec:** `docs/superpowers/specs/2026-09-23-frontend-foundation-design.md`

## Global Constraints

- 本地开发和生产预览端口固定为 `43187`；冲突时报错，不结束其他进程，不自动换端口。
- 只创建 14 条公开展示路由：`/`、`/ai`、`/ai/llm`、`/ai/image`、`/ai/video`、`/idc`、`/idc/vps`、`/idc/bare-metal`、`/idc/colocation`、`/idc/gpu`、`/madeinchina`、`/network`、`/energy`、`/about`。
- 访客正文只取 `docs/网站各板块介绍页文案.md` 中每页“页面正文开始”至“页面正文结束”的内容。
- 不创建 new-api、账户、控制台、支付、价格、在线生成、伪登录或假表单功能。
- 不编造联系方式、套餐、库存、SLA、资质、案例、模型接入状态或合作资源归属。
- 首页以大模型业务优先，IDC、信创、专线和能源随后且保持同级。
- HeroUI 只使用 v3 API：无 `HeroUIProvider`，Tailwind 样式先导入，HeroUI styles 后导入，组件编码前读取安装版本文档。
- 公开正文默认使用 Server Components；只把有状态交互划入 Client Components。
- 未配置真实站点 origin 的构建必须 noindex；正式发布不得输出 localhost canonical。
- 产品代码遵循 TDD：先写失败测试并确认失败原因，再写最小实现。
- 原始 `product/`、完整 `extracted/`、虚拟环境和临时目录不进入 Git；品牌 Logo 可以纳入。

## Review Focus

1. `NEXT_PUBLIC_SITE_URL` 缺失、仅空白或格式无效时：本地仍可预览，robots 保持 noindex；显式无效 URL 必须让测试或构建失败，不能产生错误 canonical。（Task 4）
2. 320px 宽度下出现长英文模型名、中文长标题或两枚按钮时：内容必须换行，整页不能横向溢出。（Task 9）
3. 手机导航中的“大模型”和“IDC”既有总览页又有子菜单时：父级页面必须可达，展开按钮状态必须可被键盘和辅助技术识别。（Task 6）
4. 没有确认电话、邮箱、微信或地址时：关于页保留协作说明，但不渲染死链、空联系卡片或假表单。（Task 3、Task 7）
5. 路由清单、导航、metadata 和 sitemap 发生漂移时：自动测试必须在构建前失败，并指出缺失、重复或无效 related path。（Task 2、Task 4）

- **Layer 1:** Task 1，建立仓库卫生、依赖和测试工具。

- **Layer 4:** Task 7 营销模板与主题。

```ts
export const DEFAULT_LOCAL_ORIGIN = "http://localhost:43187";

type PublicEnv = {NODE_ENV?: string; NEXT_PUBLIC_SITE_URL?: string};

export function getSiteOrigin(env: PublicEnv = process.env): string {
  const raw = env.NEXT_PUBLIC_SITE_URL?.trim();
  if (!raw) return DEFAULT_LOCAL_ORIGIN;
  try {
    return new URL(raw).origin;
  } catch {
    throw new Error("Invalid NEXT_PUBLIC_SITE_URL");
  }
}

export function isIndexable(env: PublicEnv = process.env): boolean {
  if (env.NODE_ENV !== "production" || !env.NEXT_PUBLIC_SITE_URL?.trim()) return false;
  getSiteOrigin(env);
  return true;
}
```
