# H200 与 RTX 5090 裸金属资源 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 将 H200 与 8 卡 RTX 5090 资源作为独立商品同步加入首页和裸金属详情页，并完成测试、推送和生产部署。

**Architecture:** 继续以 `bareMetalResources` 作为唯一事实来源。详情组件渲染完整字段，首页组件遍历同一目录并抽取四项核心规格；联系方式为空时不渲染咨询内容，样式只处理纵向卡片栈和单项网格占位。

**Tech Stack:** Next.js 16.3.6 App Router、React 19 Server Components、TypeScript、Tailwind CSS 4 全局样式、Vitest、Playwright。

**Spec:** `docs/superpowers/specs/2026-11-03-h200-rtx5090-resources-design.md`

## Global Constraints

- 新增商品名分别为 `H200 8卡集群节点` 与 `8× RTX 5090 裸金属节点`。
- H200 展示 128 台、IB 组网、风冷、五年合作周期、参考价 ¥170,000/台/月（可议价）及需求文档中的全部硬件参数。
- RTX 5090 展示 128 台、西南区域、约 1 个月交付、含机房/电/网最低 ¥16,500/月、自备机房与组网最低 ¥13,500/月。
- 新资源 `contacts` 为空，不复制 DeepBlue 电话；组件不得输出空“咨询”。
- DeepBlue Server 既有配置、价格、电话和首页摘要行为不得回归。
- 首页和详情页使用同一资源目录，公共内容保持服务端渲染。
- 生产继续仅绑定 `127.0.0.1:43187`，使用完整提交 SHA 镜像并保留回滚材料。

## Review Focus

- `4090` 与 `5090` 冲突必须收敛为与 32GB 参数一致的 RTX 5090，不能同时公开两个型号。
- 三张卡的价格、合作/交付条件和规格必须各自隔离，不能串卡。
- 空联系人不能留下空咨询标签，也不能改变 DeepBlue 电话在公共内容中的唯一出现次数。
- 360–1440px 的长网络、价格和供电字段不能导致页面横向溢出或卡片内部裁切。
- 首页必须实际渲染三张具名商品卡，而不只是让型号文字出现在 Next.js 内联数据中。
