# 需求摘要

## 目标

在现有资料仓库中从零建立光波互联中文官网的前端基础框架，采用 Next.js App Router、TypeScript、React 19、HeroUI v3、Tailwind CSS 4 与 pnpm。

## 本轮范围

- 接入并锁定兼容的前端依赖，保留 `pnpm-lock.yaml`。
- 将本地开发地址固定为 `http://localhost:43187`，端口冲突时直接报错，不结束其他进程，也不切换端口。
- 配置官方 HeroUI React MCP，并验证组件列表与组件文档能力。
- 先独立生成 HeroUI React v3 的参考索引，再在不覆盖现有规则的前提下合并项目约定。
- 建立白底蓝色的浅色科技主题、统一公开页布局、响应式导航与页脚。
- 首页使用现有真实文案，先展示大模型业务，再展示 IDC、信创、专线和能源。
- 创建 14 个公开页面路由骨架，并带入每页标题、简介与核心业务模块。
- 为公开页规划和实现独立 metadata、canonical、sitemap 与 robots。
- 运行类型检查、lint、生产构建，并在 43187 端口验证桌面与手机视口。

## 明确不做

- 不接入 new-api。
- 不开发账户、客户控制台、支付或在线 AI 创作工具。
- 不创建伪登录、伪价格、假成功表单或无真实去向的入口。
- 不编造联系方式、套餐、库存、SLA、资质、案例或模型接入状态。
- 不把合作伙伴资产、资质和案例写成光波互联自有。
- 不通读原始 PDF/PPT；仅在摘要或提取文本不足时按需查看。

## 内容与素材约束

- 页面内容以 `docs/网站各板块介绍页文案.md` 中每页“页面正文开始”至“页面正文结束”为准。
- 14 条公开路由以 `docs/首期页面清单与数量.md` 为准。
- 联系方式和其他缺失项以 `docs/官网展示页开发准备清单.md` 为准，不生成访客可见占位文案。
- Logo 使用 `profile/logo.png`。
- 其他图片只从已提取素材中精选并实际查看后使用；避免整页截图、证照、第三方名称和客户信息。

## 已知环境状态

- 当前目录不是 Git 仓库，因此无法执行要求中的规格提交、分支提交和任务归档提交。
- 当前会话未暴露 HeroUI MCP；本机 Codex 配置也未登记该 MCP。
- 本机已有 HeroUI v3 技能和按需文档脚本。
- 本机运行时为 Node.js 22.22.3、pnpm 9.15.4。
