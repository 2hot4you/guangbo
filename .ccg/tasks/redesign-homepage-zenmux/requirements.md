# 首页与通用组件视觉重构

- 以 ZenMux 首页为布局与色调参考：大字号、宽留白、黑白高反差、浅灰分区和少量荧光色强调。
- 保留光波互联现有中文业务文案与真实内部链接，不复制 ZenMux 的品牌文案或素材。
- 本轮只交付首页和通用组件：Header、桌面/移动导航、Footer、面包屑规则、通用内容条目。
- 首页不显示面包屑；一级栏目页也不显示，二级详情页保留弱化面包屑。
- 导航不显示“当前栏目”或“当前页面”等可见状态文案，只用视觉状态和 `aria-current`。
- 首页不使用成排边框卡片与蓝色下划线标题，改用信息带、分隔线与整行导航。
- 保持 HeroUI v3、键盘操作、移动端适配和现有路由不变。
- 首页 `01–05` 五个业务域必须直接完整展开，不使用折叠面板或展开/收起按钮。
- AI 层级内展示三类模型能力与模型生态；COMPUTE 展示 VPS、裸金属、机柜托管和 GPU 算力；信创、专线与能源分别展示其主要服务方向。
- 桌面端业务域采用左右交错节奏：相邻板块轮换标题列与详情列；移动端始终保持标题在详情之前。
- AI、COMPUTE、XINCHUANG、LINK、ENERGY 五个业务域都保留圆形轨道图形；首页首屏和业务圆形使用低频 CSS 动效，并在 `prefers-reduced-motion` 下完全停止。
- 首页首屏从长距离 sticky 滚动故事收回为普通五屏轮播 Banner；支持自动轮播、左右按钮、圆点、键盘方向键与横向触控滑动，且不得拦截页面纵向滚动。
- `prefers-reduced-motion` 下轮播停止自动播放并取消位移动画；鼠标悬停、控件聚焦和页面隐藏时暂停自动播放。
- 首页模型生态使用 React Bits `LogoLoop`，展示 `@lobehub/icons` 固定版本中完整的 Provider 与 Model 两个分类，不包含 Application 分类。
- Provider 与 Model 使用两条反向循环轨道，图标来自 LobeHub 官方 CDN；每个图标保留名称、替代文本和加载失败回退，避免将数百个 SVG React 组件打入首页脚本。
