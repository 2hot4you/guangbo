# Review: add-header-mega-menu

## Scope

- 为桌面端增加覆盖主内容宽度的行业 Mega Menu，并在移动端抽屉中复用同一份导航数据。
- 让 AI、IDC 细分页及信创、专线、绿电的产品/解决方案锚点可从 Header 直接到达。
- 将信创、专线、绿电三个行业内页分别扩充到 12 个正文模块，文案依据项目已有材料整理。
- 补齐同页锚点、跨页锚点、重复锚点、浏览器前进后退及移动端抽屉关闭后的聚焦行为。

## Analysis and review

外部 CCG wrapper 在当前环境不可用，因此按同等要求使用两名独立内部代理完成并行分析，并由产品/内容与工程两个方向独立审查。

- 产品与内容审查：通过，无 Critical / Warning。
- 工程审查：首轮发现键盘焦点、延迟 history 提交、重复同一锚点、移动端抽屉四个边界问题；修复并补充回归测试后复审通过。
- 最终路由顶部回归：修复路由顶部 effect 与锚点 revision 相互清理 RAF 的竞态后复审通过。

非阻断信息项：能源菜单中的碳资产分类后续可按业务口径调整；未添加未经确认的咨询入口；专线内容数据顺序与视觉展示顺序可在后续内容维护时统一。

## Verification

- `pnpm verify`：通过；Vitest 184/184、类型检查、Lint、生产构建均通过，生成 18 个静态页面。
- `pnpm test:e2e -- --reporter=line`：通过；桌面端与移动端共 118/118 个场景。
- 覆盖 Mega Menu 的 hover、键盘、触控、Escape、移动抽屉、所有 Header 深链、锚点唯一性与可见性、同页重复导航、前进后退、页面顶部复位及行业模块数量。

## Result

无未解决的 Critical 或 Warning。实现符合本任务需求，可以交付本地验收。
