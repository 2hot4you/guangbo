# Header 全宽 Mega Menu

## 用户目标

- 共享 Header 的行业菜单在桌面端悬停时展开全宽下拉面板。
- 面板展示对应行业的产品、能力或解决方案入口。
- 点击子菜单进入已存在的详细页面，或定位到现有长页内的对应内容模块。
- 解决 VPS 等详细内页缺少主导航入口的问题。
- 依据项目内既有资料扩充信创、专线、绿电内容，不停留在单一概览页。
- 每个行业至少形成清晰的产品、解决方案、应用场景与交付板块，拆分足够细致。
- 只使用资料能够支持的产品与方案口径，不把合作伙伴资产、资质或案例改写为光波互联自有。

## 当前路由与可复用入口

- 大模型与 AIGC：`/ai`、`/ai/llm`、`/ai/image`、`/ai/video`。
- IDC 与算力：`/idc`、`/idc/vps`、`/idc/bare-metal`、`/idc/colocation`、`/idc/gpu`。
- 信创与企业数字化：`/madeinchina` 及其页面内容锚点。
- 全国专线租赁：`/network` 及其页面内容锚点。
- 绿电与清洁能源：`/energy` 及其页面内容锚点。
- 首页、关于我们保持直接链接；登录与注册继续保留在右侧。

## 交互与质量约束

- 桌面端支持 hover、键盘聚焦、Escape 关闭和从触发项移动到面板时保持展开。
- 移动端沿用抽屉，并将所有行业组织成可展开分组。
- 当前栏目与当前页面状态继续通过语义属性和视觉状态表达，不增加“当前栏目”等文案。
- 导航链接须在初始 HTML 中存在，保留可访问性与可索引性。
- 尊重减少动态效果偏好，不影响页面纵向滚动。
